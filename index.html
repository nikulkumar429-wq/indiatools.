Frequently Asked Questions

Are these tools free?

Yes. The tools in this version are designed to work without requiring an account.

Are my files uploaded?

Most image processing happens locally in your browser. No server upload is required for those tools.

Can I use this on mobile?

Yes. The website is responsive and designed for both phones and computers.

Does PDF conversion work offline?

Some PDF functions use browser libraries loaded from the internet, so the first page load requires an internet connection.
